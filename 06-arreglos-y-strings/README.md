# Modulo 06 -- Arreglos y Strings

Los arreglos permiten almacenar multiples valores del mismo tipo en memoria contigua. Los strings en C son arreglos de caracteres terminados en `'\0'`. Este modulo explora ambos conceptos fundamentales.

## Archivos del modulo

- `01_arreglos_unidimensionales.c` — Declaracion, inicializacion y recorrido de arreglos 1D
- `02_arreglos_multidimensionales.c` — Matrices y operaciones con arreglos 2D
- `03_strings.c` — Cadenas de texto y funciones de `string.h`
- `04_agenda_contactos.c` — Proyecto practico: lista de contactos
- `05_ejercicios.c` — Ejercicios para practicar
