# Modulo 03 -- Operadores

Los operadores son las herramientas que permiten transformar datos, comparar valores y manipular bits directamente. En C, entender los operadores es esencial porque el lenguaje trabaja cerca del hardware y muchas operaciones afectan la representacion binaria de los datos.

## Archivos del modulo

- `01_operadores_aritmeticos.c` -- Operadores aritmeticos, asignacion compuesta e incremento/decremento
- `02_operadores_comparacion.c` -- Operadores de comparacion y operador ternario
- `03_operadores_logicos_y_bitwise.c` -- Operadores logicos y operaciones a nivel de bits
- `04_calculadora_impuestos.c` -- Proyecto practico: calculadora de impuestos y descuentos
- `05_ejercicios.c` -- Ejercicios practicos para reforzar lo aprendido
