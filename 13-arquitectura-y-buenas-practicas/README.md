# Modulo 13 -- Arquitectura y Buenas Practicas

Modulo avanzado que cubre organizacion de proyectos en C, manejo profesional de errores, tecnicas de debugging y un proyecto practico que integra todos los patrones vistos.

## Archivos del modulo

- **01_estructura_proyecto.c** -- Como organizar un proyecto en C, separacion de responsabilidades, responsabilidad unica por funcion y convenciones de nombre
- **02_manajo_errores.c** -- Codigos de retorno, mensajes de error con perror, programacion defensiva y patrones de validacion
- **03_debugging.c** -- Macros de depuracion, compilacion condicional con DEBUG y estrategias para diagnosticar problemas
- **04_gestor_tareas.c** -- Mini-proyecto practico: gestor de tareas que combina arquitectura limpia, manejo de errores y modo debug
