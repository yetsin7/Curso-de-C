# Documentacion oficial de C

Este curso se apoya en documentacion tecnica real para que aprendas C con una
base mas solida y no dependas solo de ejemplos aislados.

## Referencias principales

- [cppreference - lenguaje C](https://en.cppreference.com/w/c/language)
  Es una referencia tecnica muy util para sintaxis, tipos y reglas del lenguaje.
- [Documentacion de GCC](https://gcc.gnu.org/onlinedocs/)
  GCC es uno de los compiladores mas usados para C.
- [Compilador Clang - documentacion](https://clang.llvm.org/docs/)
  Clang es otro compilador muy usado, con herramientas modernas de diagnostico.

## Recursos clave para estudiar

- [Tipos, operadores y expresiones](https://en.cppreference.com/w/c/language/conversion)
  Aqui entiendes como C maneja valores y operaciones.
- [Control de flujo](https://en.cppreference.com/w/c/language/statements)
  Incluye `if`, `switch`, `for`, `while` y otras estructuras.
- [Funciones](https://en.cppreference.com/w/c/language/function_definition)
  Sirven para dividir un programa en partes reutilizables.
- [Punteros](https://en.cppreference.com/w/c/language/pointer)
  Los punteros guardan direcciones de memoria, una de las partes mas importantes
  y delicadas de C.
- [Memoria dinamica](https://en.cppreference.com/w/c/memory)
  Explica `malloc`, `calloc`, `realloc` y `free`.
- [Manejo de archivos](https://en.cppreference.com/w/c/io)
  C permite leer y escribir archivos de forma directa.

## Orden recomendado

1. Aprende la sintaxis base del lenguaje en cppreference.
2. Compila ejemplos pequenos con GCC o Clang.
3. Estudia punteros y memoria con calma.
4. Pasa luego a archivos, librerias y proyectos mas reales.
