# Modulo 04 -- Control de Flujo

En este modulo aprenderas las estructuras que permiten a un programa tomar decisiones y repetir acciones. El control de flujo es la base de toda logica computacional.

## Archivos del modulo

- `01_condicionales.c` -- Sentencias if, else if, else y switch/case
- `02_bucle_for.c` -- Bucle for, bucles anidados y patrones de impresion
- `03_bucles_while.c` -- Bucles while, do-while, break y continue
- `04_menu_interactivo.c` -- Proyecto practico: menu interactivo
- `05_ejercicios.c` -- Ejercicios para practicar

## Como compilar

Cada archivo se compila de forma individual:

```bash
gcc -Wall -Wextra -std=c11 -o nombre_archivo nombre_archivo.c
```
