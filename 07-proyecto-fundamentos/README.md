# Modulo 07 -- Proyecto Fundamentos

Este modulo combina todos los conceptos aprendidos en los modulos 01-06 del curso de C en proyectos practicos completos. Aqui pondras a prueba tus conocimientos de variables, operadores, funciones, control de flujo, arreglos y manejo de entrada/salida.

## Archivos del modulo

- **01_calculadora_propina.c** -- Calculadora de propina con funciones y operaciones aritmeticas
- **02_adivinanza_numero.c** -- Juego de adivinanza de numero con bucles y condicionales
- **03_checklist.md** -- Lista de verificacion para validar los fundamentos
- **04_reto_extra.md** -- Desafio adicional: Sistema de Notas

## Instrucciones

1. Compila cada archivo `.c` individualmente con el comando indicado en su encabezado
2. Ejecuta los programas y verifica que funcionen correctamente
3. Usa la checklist para asegurarte de dominar todos los conceptos
4. Intenta completar el reto extra sin ayuda
